## Что нужно было сделать
По заданию требовалось:
- Подключить стили тремя способами: внешний файл, внутренний `<style>`, и один элемент с инлайн-стилями
- Использовать CSS-переменные в `:root` для цветов и шрифтов
- Показать все типы позиционирования: `static`, `relative`, `absolute`
- Сделать состояния элементов: `:hover`, `:active`, `:focus`, `:visited`
- Следить за контрастностью текста (не меньше 4.5:1)

## Как я это реализовал

### Подключение стилей
- **Внешний файл `style.css`** — сюда вынес все основные стили: шапку, сетку, карточки, форму
- **Внутренний блок `<style>`** — тут прописал стили для заголовков `<h2>`, чтобы они были покрупнее и с нормальным межстрочным интервалом
- **Инлайн-стили** — для картинки с едой задал `object-fit: cover` прямо в HTML, чтобы она красиво обрезалась

### Цветовая схема
Вариант предполагал кремовый фон и терракотовый акцент. Я задал это через переменные:

```css
:root {
    --main-color: #FDFBF7;    /* кремовый фон */
    --accent-color: #B84A35;  /* терракотовый для кнопок и заголовков */
    --text-color: #332A25;    /* тёмно-коричневый текст */
}
